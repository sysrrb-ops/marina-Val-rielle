MARINA VALÉRIELLE — ULTRA-LUXURY WEBSITE DEMO

FILES
- index.html  Main website page and content
- styles.css  Responsive visual design, layout, typography and image styling
- script.js   Mobile navigation, yacht filters, save buttons and demo enquiry form

HOW TO OPEN
1. Extract the ZIP file to a folder.
2. Open index.html in a modern browser (Chrome, Edge, Firefox or Safari).
3. An internet connection is recommended for remote photography and Google Fonts.

FUNCTIONAL FEATURES
- Responsive layout for desktop, tablet and mobile
- Sticky navigation and mobile menu
- Yacht collection filters (All / Day charters / Overnight / Celebrations)
- Interactive save/favourite buttons
- Enquiry links preselect matching services in the form
- Booking enquiry form validation and confirmation preview
- Date input prevents selecting dates before today

IMPORTANT
This is a fictional concept brand for educational/demo use. Prices, services and contact information are illustrative. The enquiry form runs locally in the browser and does NOT send data, create a real reservation, accept payment, or connect to a database. Photography and web fonts load from external services and may not appear offline.
